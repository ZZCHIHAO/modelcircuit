# S9 独立分割推理实施计划

版本为 `v0.9.0-alpha.1`。通过同一个原生桌面应用加载 S8 或更新训练产物中的 `run_spec.json` 和匹配的检查点，对新影像运行推理。

1. [x] 从训练快照恢复图、模态、输入尺寸与类别值，核对检查点身份。继续使用本地工作进程、设备互斥、进度、取消与产物记录。
2. [x] 处理单文件和同格式目录。整图模式复用训练时的归一化与重采样。滑窗以训练输入尺寸在原始网格上推理，处理奇数网格和窄于窗口的轴，以重叠区域的加权得分决定类别。
3. [x] 在桌面增加独立推理入口、结果重新打开、按样本和原始切片浏览，以及 PNG/NIfTI 掩码导出。
4. [x] 对照 S8 固定尺寸检查点的直接推理，独立校验滑窗合并、边缘覆盖、原始仿射和切片定位。统一 EXE 在 CPU 和 CUDA 验收，提交版本 PR。
