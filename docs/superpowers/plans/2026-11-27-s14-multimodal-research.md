# S14 传统机器学习与多模态实验

目标版本 `v0.9.5-alpha.1`。在现有 Windows 桌面工作台完成表格建模和病例级多模态分类。以 S13 分支的 `c30db47` 为基线，按阶段提交 PR。

| 工作 | 接入方式 | 验收 |
| --- | --- | --- |
| 表格随机森林 | `table_csv` 保存原始数值和分类特征及患者分组。随机森林分类、回归作为可拖入的估计器。每折基于开发集重新拟合填补、编码和可选标准化，同患者不跨折。最终拟合用开发集，单独评估冻结测试集。 | 试验含重复患者、缺失数值与验证或测试独有类别。导出折成员、逐折分数和测试集预测。断言预处理只看到该折训练数据。 |
| 病例数据 | `multimodal_csv` 用病例 ID、患者 ID、标签、影像路径和表格字段描述一行病例。支持 CT、已配准 MRI、独立二维影像及由三维体派生的切片或投影。记录有序模态、源摘要、预处理与划分。 | 断言患者分组、影像与表格行对应、跨划分重复检查及按病例定位的缺失、重复和冲突错误。 |
| 画布训练 | `input_ports` 绑定选用的模态和具名接口。`tensor-v1` 保留二维、三维和表格的不同轴。共享现有 PyTorch 分类训练、探针和检查点。提供可编辑的起始图和单模态及融合选择。 | 原生回调完成 CT 加表格、MRI 加表格和二维切片加三维体训练。固定划分后可比较单模态和融合结果。 |
| 工程复现 | 工程数据锁使用相对路径和源摘要，绑定后复跑相同折和病例。独立 `run.py train` 实际运行对应的表格或影像后端，从测试集生成预测。 | 把导出工程与合成数据复制到其他目录，核对数据锁、端口、折和预测。清单拒绝数据替换。 |
| 交付 | 版本号、中文指南、统一 EXE、变更记录和阶段 PR。使用现有 Windows Python 及 CUDA 环境，用程序化原生回调核对工作台。 | 老工程测试、核心和桌面回归、CPU 表格流程、CPU 和 CUDA 影像融合及 EXE 启动。生成诊断数据留在本机临时目录。 |

S14 使用可重复的合成病例验证软件行为。表格与多模态首次交付分别覆盖分类及回归、影像融合分类。分割继续使用 S13 的配对影像协议。文本、报告与大模型接入由后续阶段覆盖。
