# S8 分割实验实施计划

**交付版本** `v0.8.0-alpha.1`。在原生桌面工作台完成二维和三维语义分割的配对检查、图搭建、训练、保留测试集评估、预测查看及导出。

**数据契约** `segmentation_csv` 使用 UTF-8 清单，指定样本 ID、患者 ID、影像路径、掩码路径和可选的划分列。二维使用栅格图像与无损整数标签。三维使用一一对应的 NIfTI，检查原始网格、有效仿射和空间单位。类别用显式整数列表映射到训练索引。影像线性插值，标签最近邻，预测以最近邻还原至原始网格。

**模型与训练契约** 使用既有具名张量端口和任务适配器。根输出 `mask_logits` 的空间维度等于掩码尺寸，类别通道对应配置中的类别值。最小起始图包含编码、下采样、上采样、跳接与分类头，支持图与 Python 往返。沿用既有训练线程外的 worker、验证选优、检查点和计算设备选择。每类累计交并统计，区分两侧均缺失的类别。
