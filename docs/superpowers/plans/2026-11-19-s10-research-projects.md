# S10 科研工程与独立复现实施计划

**目标** `v0.9.1-alpha.1` 交付可迁移、可复跑、可编辑的科研项目。先验收 ImageFolder 二维分类与 NIfTI 配对三维分割。

**契约** 工程目录包含有版本的 `project.json`、受支持的 `model.py`、数据清单、`run.py`、依赖说明和运行所需的核心 Python 源码。数据在打开工程后从目标目录重新核对。绑定后的运行沿用当前监督训练和推理约定。运行结果由独立 JSON 索引及相对路径连接到产物。

1. [x] 用测试验证工程迁移后固定原数据划分，拒绝更改内容的同名文件，并从 Python 恢复实际结构、连接和参数共享。实现导出、读取和数据绑定。
2. [x] 从仓库以外执行导出工程，使用同一训练和推理函数生成产物。记录模型、数据、环境、结果和失败状态。开放结果读取和可比性判断。
3. [x] 接入桌面工程页、示例、重新绑定和运行记录，程序化测试导出、打开、运行、结果复查。按相同数据与指标协议对照历史结果。
4. [x] 验证本机隔离环境与可用的第二台机器的训练和推理。检查 S8/S9 兼容，使用统一 EXE 验收，补充指南并提交版本 PR。

## 验收记录

后端 400 项通过、1 项跳过，原生桌面 284 项通过。统一 EXE 由源码 `4b4b5e3` 构建，同一文件在 CPU 与 RTX 4060 Laptop GPU 上验收。EXE 导出工程在独立 Python 环境运行检查、训练与推理。保留原分割数据路径的相对位置后，可以用工程清单恢复由绝对路径 CSV 导出的配对。

Windows 和 Linux 都用 CPU 完成合成二维分类与三维分割的训练和推理。模型和数据身份、数据划分、训练步数一致，测试指标误差在 `1e-5` 以内。S8 的二维和三维工作区可打开，附带旧检查点的工程可复现掩码。操作见 [S10 工程指南](../../../studio/native/S10_PROJECT_GUIDE.md)。
