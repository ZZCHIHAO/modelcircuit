## 2. 独立算例：标准结构、形状、参数及状态

固定算例采用官方版本结构资料：torchvision v0.21.0 `resnet.py` 的 BasicBlock/stem/[2,2,2,2]，PyTorch v2.6.0 `batchnorm.py` 的默认状态语义。它们只是固定版本依据，未安装 torchvision、下载模型/数据或加载预训练权重。参数、shape 和计费数值由本地纯数学夹具独立计算，不调用生产 shape helper 或生产网络。

- `https://raw.githubusercontent.com/pytorch/vision/v0.21.0/torchvision/models/resnet.py`
- `https://raw.githubusercontent.com/pytorch/pytorch/v2.6.0/torch/nn/modules/batchnorm.py`

本轮已取回并核对torchvision固定tag源码（其权重元数据同时记载11,689,512参数），原文与SHA-256记录在 `torchvision-v0.21.0-resnet-official-source.log` / `official-source-provenance.json`。PyTorch固定tag的远端读取超时，未伪称取回成功；BN语义改为只读核查现有 `torch==2.6.0+cpu` 的安装源码，见 `local-torch-batchnorm-source.log` / `local-torch-batchnorm-provenance.json`，没有据此实例化或执行BN。

卷积/pool 的空间公式为 `floor((L+2P-D*(K-1)-1)/S+1)`，此处 dilation=1、ceil_mode=False。Conv 无 bias 参数数为 `Cout*Cin*K*K`；BN 默认 affine 参数数为 `2*C`；fc 参数数为 `512*K+K`。

## 3. 独立算例：嵌套计费为什么超限

只把未知首轴按 bound=1 或2替代，硬上限保持 **20,000,000 / 16,777,216 / 134,217,728**，不开放非batch未知维，不给旧模型新增actual≤64限制。

声明的候选拓扑：根图单次调用entry；entry含stem、stage1..4、pool、flatten、fc；stage各含两个block；stage2..4的block0各含projection。各实例各调用一次，17个独立定义（不假设相同shape的block定义复用），69个primitive实例、17个chip实例；根图只有logits输出。不含额外公开stage输出、Identity调用、参数绑定或布局数据。

对一个scope，令 `I` 为输入元素、`P` 为该scope primitive调用输出之和、`Ochild` 为其chip调用输出之和，子scope记为child：

```text
执行路径元素计费估计 R(scope) = I + P + Σ[R(child)+Ochild]
当前静态推导工作计费 T(scope) = I + P + Σ[2*T(child)+Ochild]
```

系数2来自 `_infer`：先在instance循环推导child以计参数，再在chip call时用实际shape推导child。`prepare_graph`又逐一推导全部definition默认图，所以总量是 `T(root)+ΣT(definition)`。它不等于实际运行时物理分配总和。根/子图输入、chip调用输出即便引用同一张量也按现有scope规则重复收费；单一scope的多输出同对象去重与此不同。当前runtime还可能保存capture快照，这里没有将快照或autograd内存视作预算元素。

## 4. 节点、字段和文件规模估算

逻辑scope数为根+17定义=18。每scope单输入单输出、每instance一个call，局部节点数为 `2+2*instance_count`。展开结构共208节点；当前解析还为每定义增加一个3节点包装scope并解析后代，所以resolve工作估计819≤2048；重复推导节点工作2864≤16,384。最大局部instance/call数8≤512，17定义≤32，最大chip边深度4≤6。

`vision_budget_audit.py`只构建有限大小估算记录，调用来源故意填 `AUDIT_ONLY`，没有可执行接线。此proxy含根及17定义的图式字段、常用primitive参数和17条definition引用，统计为：

| 计数口径 | proxy数值 | 现有限制 |
|---|---:|---:|
| 字典字段数 | 1151 | 无独立字段总数限制，受值数限制 |
| native口径值数（不计键） | 1452 | 20,000 |
| schema口径值数（计键） | 2603 | 20,000 |
| JSON深度（定义平铺、靠ID引用） | 8 | 32 |
| 紧凑UTF-8字节 | 18,220 | 图/芯片读入4 MiB |
| 缩进UTF-8字节 | 42,777 | workspace读入8 MiB |

这些是**已声明proxy的准确计数、未来生产闭包的估算**。尚无真实source引用、public bindings、布局、选配stage输出、生产序列化包或Python源码，不能用proxy结果验收生产闭包大小；A4必须对实际产物重新运行preflight、validate_graph、chip合成根、序列化和Python导入限制。独立JSON提供每一scope和69个叶算子的shape/元素/参数/config，便于审查逐项复算。
