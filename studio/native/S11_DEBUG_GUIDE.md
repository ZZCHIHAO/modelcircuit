# S11 可视化调试

`v0.9.2-alpha.1` 为原生 Windows 桌面版增加端口诊断、样例前向、按批单步训练和参数扫描。

1. 从左侧组件库搜索并拖放组件。搜索支持常用名称，例如「相加融合」「拼接融合」「Linear」「ResNet」「ViT」「SVM」。悬停可查看输入输出、初始化和执行方式。
2. 悬停画布端口查看当前形状和数据类型。已声明的轴同时显示。已知维度不匹配时，目标端口标红，底部状态栏给出出错维度。还缺上游输入时，连接后提示「待验证」。
3. 点击画布输出端口名添加探针。双击芯片进入具体调用的页签，可以观察芯片内部端口。多个调用如果引用同一个实例，激活按调用记录，权重按实例记录。
4. 在右侧「调试」中选择 CPU 或一张可用的 CUDA 显卡、样本来源和批大小。使用图像时，先在「实验」页配置 ImageFolder 分类训练集，再选「图像训练集」。结果显示在底部「调试测量」。
5. 在主模型上选中组件，从「参数扫描」选择一个数值参数，输入 2 至 8 个用英文逗号分隔的值。比如给「固定标量缩放」的 `factor` 输入 `0.5, 1, 2`。各取值从同一随机种子、同一批数据起步，保持权重结构一致。

| 调试操作 | 实际执行 | 可观察结果 |
| --- | --- | --- |
| 检查结构 | 校验图和端口契约 | 不兼容连接、缺少的输入、模型参数量 |
| 样例前向 | 一次评估模式前向 | 输出、端口激活、总耗时 |
| 训练一步 | 用当前学习率、优化器对一个批次执行前向、反向和一次更新 | 损失、端口梯度、参数更新前后值和更新量 |
| 参数扫描 | 同一批次按各取值依次做样例前向 | 输出统计、分类损失（图像训练集） |

每次调试从模型初始化开始，使用运行快照。调试记录保存在工作区 `runs` 中。全量训练继续由「实验」页启动。单步适用范围为合成分类和 ImageFolder 分类。SVM 使用实验页的拟合与评估。

探针默认从张量起点采样。「探针采样」可指定展平后的起点，每个端口最多记录 128 个值。梯度采样使用同一位置。大参数张量的 ΔW 显示对应采样范围，选择的实例优先采集。分维的注意力热图仍可从原有张量探针打开。

统一 EXE 继续使用 `%LOCALAPPDATA%\ModelCircuitStudio-S10` 中的工作区和运行记录。双击 `studio/启动模路.cmd` 启动。开发者使用 `./studio/build-s4-desktop.ps1 -Stage S11` 构建，以 `--data-dir DIR --s11-render-check REPORT --check-device cpu` 运行程序化验收。CUDA 验收可将设备换成 `cuda:0`。
