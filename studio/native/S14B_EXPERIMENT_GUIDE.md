# 工程迁移、指定样本与无监督实验

在 `v0.9.5-alpha.2` 中，双击 `studio/启动模路.cmd` 打开统一 Windows 桌面版。

1. 配置数据和画布后，在「工程」选择新目录并点「导出工程」。数值 CSV 分类、回归、表格机器学习和无监督表格可勾选「附带数据 CSV」。
2. 把整个工程目录复制到另一台机器。在模路的「工程」面板打开 `project.json`，可编辑恢复的画布。工程内的 CSV 会自动核对。工程引用外部数据时，选择对应目录或文件并点击「核对数据并恢复画布」。
3. 「运行保存的工程」使用目录里的模型与设置。改动画布后可从「实验」跑当前设计，或再次导出当前设计。导出目录内含可编辑的 `model.py`、数据清单、依赖和 `run.py`。安装导出目录声明的 Python 依赖后，可运行以下命令。参与打包的 CSV 可省略 `--data`。

```powershell
python run.py check
python run.py train --out runs/first
```

## 指定样本与 A/B 对照

在「实验」检查数值分类 CSV、回归 CSV 或 ImageFolder 图片。打开「调试」，选「实验数据」，选择数据划分，用「添加第 N 个样本」按划分内的顺序选择，也可填写已有样本 ID。留空时从当前划分的第一项开始。点画布端口加探针，再运行「样例前向」或在训练集运行「训练一步」。

测量完成后点「设为对照 A」，改动画布后用相同输入配置再测。结果页显示样本 ID、损失差值和指定端口的 A/B 观测。对照 A 保留在当前会话。完整训练的结果可以在「工程运行记录」中另作对照。

## PCA 和 K-means

1. 选择「无监督表格（PCA / K-means）」任务，选择 CSV 和数值特征列，按需开启标准化。检查数据后选择 PCA、K-means 或 PCA → K-means 起始图。也可以从「传统机器学习模型库」拖入组件并连接。
2. 在画布调整主成分数或簇数，使用 CPU 拟合。查看「最终评估与文件」中的主成分解释方差、二维投影、簇大小和簇内平方和。
3. `projection.csv` 保留所有样本和维度，`metrics.json` 记录结果及配置相关统计。无监督任务对所选数据整体拟合。比较簇内平方和时使用相同的聚类特征空间。

统一桌面构建命令为 `./studio/build-s4-desktop.ps1 -Stage S14B`。
