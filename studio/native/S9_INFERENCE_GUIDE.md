# S9 分割推理 · v0.9.0-alpha.1

打开模路 Windows 桌面版，在右侧选择「推理」。S9 可以使用 S8 或更新版本保存下来的分割训练产物。

1. 选择训练产物目录中的 `run_spec.json`。程序默认读取同目录的 `best.pt`。如果检查点移动过，使用「检查点」字段选择匹配的 `.pt`。刚在当前窗口完成训练时，可以点击「使用本次训练的最佳权重」。训练记录提供模型结构、数据格式、通道、标签值和输入尺寸。
2. 选择新影像，或选择装有同格式影像的文件夹。二维模型可用与训练兼容的图片。三维模型读取单通道 `.nii` 和 `.nii.gz`。文件夹按文件名顺序读取当前层的兼容文件。图片和 NIfTI 的预处理和归一化与训练一致。
3. 选择推理模式和设备，再点击「开始推理」。使用同一个桌面程序可选 CPU 或一张可用的 CUDA 显卡。
4. 在底部「推理结果」切换影像。三维影像可用滑块浏览每张原始体素切片。左侧显示影像，右侧显示掩码叠加。较大的切片用缩略图预览，查看像素级结果可打开导出的掩码。导出保留源图的高宽和深度，NIfTI 还保留有效仿射和空间单位。导出的掩码使用训练时的标签值。
5. 保存 `inference.json` 及它旁边的 `masks` 和 `views` 目录，即可通过「打开已保存的推理结果」再次查看。记录包含训练快照与检查点摘要、输入文件摘要、设备、窗口尺寸和推理模式。

| 模式 | 处理方式 |
| --- | --- |
| 整图缩放 | 把整幅影像重采样到训练输入尺寸，做一次前向，再将类别掩码还原到原始网格。适合作为对照，行为与 S8 测试集预测一致。 |
| 原始网格滑窗 | 用训练输入尺寸在原始网格上提取窗口。较窄的轴采用边缘填充。重叠区域按位置加权合并类别分数，最后裁到原始尺寸。重叠比例可调，重叠增多也会增加窗口数。 |

GPU 每次处理一个窗口，CPU 按片合并分数。整图和滑窗在不同尺寸的测试输入上可能产生不同预测。比较两种模式时，应按自己的验证集和任务指标选择。三维预览沿 NIfTI 的原始体素 Z 轴，轴方向和间距以导出掩码及报告中的仿射为准。

在依赖已配置的项目根目录运行 `./studio/build-s4-desktop.ps1 -Stage S9` 可构建统一 EXE。双击 `studio/启动模路.cmd`，也可直接打开 `studio/dist/s9/ModelCircuitStudio/ModelCircuitStudio.exe`。移动时保留整个应用目录。工作区默认位于 `%LOCALAPPDATA%\ModelCircuitStudio-S9`。
