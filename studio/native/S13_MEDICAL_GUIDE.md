# S13 医学影像分割

`v0.9.4-alpha.1` 支持在同一个 Windows EXE 上用 CPU 或 CUDA 单卡做三维 CT、MRI 分割。启动 `studio/启动模路.cmd`。便携目录是 `studio/dist/s13/ModelCircuitStudio`，移动时保留整个目录。

## 准备病例 CSV

在「实验」选择「2D / 3D 医学影像分割」。打开「数据设置」，选择「DICOM CT + NIfTI 掩码」或「MRI NIfTI + NIfTI 掩码」。病例表至少包含样本 ID、患者 ID、参考影像路径、掩码路径。相对路径以 CSV 所在目录为根，也可以指定数据根目录。

MRI 示例中的 `image_path` 是通道 1，`flair_path` 是通道 2。

```csv
sample_id,patient_id,image_path,mask_path,split,flair_path
case-01,p01,mri/case-01/t1.nii.gz,labels/case-01.nii.gz,train,mri/case-01/flair.nii.gz
case-02,p02,mri/case-02/t1.nii.gz,labels/case-02.nii.gz,val,mri/case-02/flair.nii.gz
case-03,p03,mri/case-03/t1.nii.gz,labels/case-03.nii.gz,test,mri/case-03/flair.nii.gz
```

- CT 的 `image_path` 指向一个 DICOM 序列目录或受支持的多帧文件。目录只放同一序列的切片。平台按物理位置排序，检查方向、位置、间距和 HU 标定，再按指定上下限窗化。首批验收覆盖原生未压缩 CT。
- MRI 的参考影像和附加序列使用三维 NIfTI。读取列名后，从左到右指定附加序列，最多三个。附加序列应事先完成配准并覆盖参考影像视野。在界面确认配准后，平台按仿射矩阵重采样到共同网格。自动配准需在外部完成。
- 掩码是与参考网格对齐的三维 NIfTI。声明实际使用的标签值，例如 `0, 255`。检查通过后才进行重采样。NIfTI 应具备有效的 qform 或 sform 与明确的空间单位。
- `split` 列可指定 `train`、`val`、`test`。选择「自动划分」时按患者分组抽样，补丁继承其病例归属。检查会拦截同一患者或同一已识别影像跨划分的情况。患者 ID 需由研究者统一并核对，跨中心重复病例仍需另行核查。

## 检查、预览与训练

1. 设置模型间距（D、H、W，单位 mm）、补丁尺寸、每病例补丁数、前景采样比例和滑窗重叠。初次可先用较小补丁试跑。模型体素网格按物理间距生成。训练、验证和测试划分各需至少一个病例。
2. 点击「检查并冻结数据摘要」后应用设置。点击「预览训练补丁…」检查影像与标注叠加。更改病例、轮次、补丁序号、通道或切片后，点击「查看」。起点是模型网格中从 0 开始的 D/H/W 体素偏移。后台按同一随机种子和训练采样规则读取补丁。
3. 点击「创建分割起始图…」，或使用自定义图。输入为 `N × C × D × H × W` 的 `float32` 张量，`mask_logits` 输出为 `N × 类别数 × D × H × W`。选 `cpu` 或 `cuda:0`，设批次与轮数后运行。
4. 每轮训练后对验证集做整卷滑窗，以模型网格的验证损失选择最佳权重。测试使用最佳权重。可在「分割预测」浏览原始网格的影像、标注与预测叠加，并导出 NIfTI 掩码。

## 推理、指标与复现

在「推理」选择匹配的 `run_spec.json` 与最佳权重。CT 选择序列目录或多帧文件。MRI 选择参考 NIfTI，并依训练配置中显示的顺序选择附加序列。应用按训练配置中的间距、窗化或归一化方式及滑窗重叠运行，一次预测一个医学病例。导出保留参考网格的尺寸、物理仿射与原始标签值。

- Dice 和 IoU 在原始参考网格计算，以有定义的病例与前景类别组合取均值。HD95 取两方向表面距离的各自第 95 百分位中的较大值，使用表面体素中心和毫米坐标。两个掩码都为空时，这三项计为缺失。只有一个掩码为空时，Dice 和 IoU 为零，HD95 计为缺失。
- `medical_case_metrics.csv` 记录逐病例与逐类别指标、有效性和参考网格。`metrics.json` 记录汇总、计数和协议。交叉熵从融合后的模型网格 logits 计算。实验对照要求相同测试协议和数据锁。
- 从「工程」导出后，使用本地病例 CSV 或数据根目录重绑。工程校验序列顺序、源内容摘要、患者划分和物理网格。使用「附带最近匹配训练的最佳权重」可同时带上匹配的推理权重。

导出的 Python 工程可以独立运行。下面是双序列 MRI 的预测命令，多条 `--sequence` 按训练顺序排列。

```powershell
python run.py predict --source 'case/t1.nii.gz' --sequence 'case/flair.nii.gz' --device cpu --out './predict-run'
```

Windows 构建命令为 `./studio/build-s4-desktop.ps1 -Stage S13`。工作区继续保存在 `%LOCALAPPDATA%/ModelCircuitStudio-S10`。本阶段的原生验收使用带已知几何和标签的合成病例。真实病例的协议适配与科学效度需按队列单独验证。S12 服务器多卡入口适用于其已验收的 ImageFolder 分类任务。
