# S8 医学影像分割 · v0.8.0-alpha.1

双击 `studio/启动模路.cmd` 打开 Windows 桌面版。在右侧「实验 → 任务」选择「2D / 3D 医学影像分割」。CPU 和单张 CUDA 显卡由同一个程序选择。

## 准备影像和掩码

新建 UTF-8 CSV，每行对应一组影像和掩码。相对路径从 CSV 所在目录解析，也可在「数据设置」选择单独的路径根目录。

```csv
sample_id,patient_id,image_path,mask_path,split
exam001,subject001,images/exam001.png,masks/exam001.png,train
exam002,subject002,images/exam002.png,masks/exam002.png,val
exam003,subject003,images/exam003.png,masks/exam003.png,test
```

同一患者的所有样本应填同一个 `patient_id`。多次检查可使用不同的 `sample_id`。已有独立测试集时应显式选择 `split` 列。选择「自动划分」会根据患者组和种子分配数据。已有研究划分应沿用原方案。检查能识别同一分组或相同解码影像跨集合，研究者还需检查患者身份及近重复影像。

| 格式 | 影像与掩码要求 |
| --- | --- |
| 二维图片 | 灰度或 RGB 影像，掩码使用 PNG 或 TIFF 单通道整数标签。影像与掩码的原始高宽须相同。带 EXIF 旋转标记的输入应事先将一对文件共同转换到正确方向。 |
| 三维 NIfTI | 单通道 `.nii` 或 `.nii.gz`。每对文件须使用相同的原始体素网格和空间单位，并提供有效的编码仿射。CT、MRI 或 OCT 已转换为对齐的 NIfTI 后可走此入口。 |

掩码标签填写实际像素值。例如二值掩码可填 `0, 1` 或 `0, 255`。背景为 `0`，其余整数从小到大排列。调小模型高宽和深度可节约显存，细小结构也可能因此从训练网格消失。程序会检查训练集中的前景，并记录各划分在模型网格上的标签分布。NIfTI 强度按样本最小值和最大值归一化。需要固定 CT 窗或统一定量标准的研究应先按实验协议预处理。

## 搭图和训练

1. 打开「数据设置」，选择 CSV 和二维或三维格式。点击「读取 CSV 列」核对分组、配对及划分列，填写标签值和模型尺寸。
2. 点击「检查并冻结数据摘要」。图像使用线性重采样，掩码使用同一采样网格上的最近邻。运行时工作进程会重新核对内容。
3. 点击「创建分割起始图…」。起始图包含卷积、池化、最近邻上采样、跳接和分割头。可以调整节点和通道数，也可以使用自己的图。模型需要输出具名的 `mask_logits`，形状为 `[N,K,H,W]` 或 `[N,K,D,H,W]`，K 等于标签数。图可导出为 Python 模型并重新导入。
4. 在「设备」选择 `cpu` 或一个可用的 `cuda:N`，设置 Epochs、批次和学习率。运行使用交叉熵训练，按验证集损失选择最佳检查点，再评估测试集。实验产物记录模型、参数、数据摘要、检查点、指标和预测。
5. 在「分割预测」选择测试样本。左、中、右分别显示输入、标注叠加和预测叠加。三维体显示模型网格上的一张代表切片，并注明切片位置。点击「导出原始网格掩码…」选目录，保存恢复至影像原始尺寸的 PNG 或 NIfTI。NIfTI 掩码保留影像的有效仿射与空间单位，类别值恢复为 CSV 配置中的值。

Dice 和 IoU 在模型网格上计算。每个类别先跨样本累计像素或体素的交集与并集，再对有定义的前景类别等权平均。当预测与标注都无该类别时，该类指标为未定义。逐类结果见 `metrics.json`，数值类别顺序见 `manifest.json`。截图、指标、预测与工作区都属于本地研究产物。

S8 覆盖固定网格训练和保留测试集预测。任意未标注文件的批量推理、逐层浏览原始三维体、滑窗分割、DICOM-SEG 和 DP/DDP 属于后续扩展。三维磁共振多序列实验仍需专门的数据配对能力。

## 本地构建与验证

在依赖已配置的项目根目录运行 `./studio/build-s4-desktop.ps1 -Stage S8`。打开 `studio/dist/s8/ModelCircuitStudio/ModelCircuitStudio.exe`，移动时保留整个 `ModelCircuitStudio` 目录。S8 的默认工作区位于 `%LOCALAPPDATA%\ModelCircuitStudio-S8`。已有工作区可以通过「打开 JSON」导入。

后端测试使用合成配对数据，对齐、标签、患者分组、实际参数更新、Python 往返及原始网格导出均有检查。桌面程序提供 `--s8-render-check <report.json> --check-device cpu` 或 `--check-device cuda:0`。实验室数据区另以 BUS-BRA 的 3 个不同病例配对验证实际 PNG 解码和冻结摘要，每对均形成 `1×96×96` 灰度张量和同网格掩码。
