# S14 表格与多模态科研实验

`v0.9.5-alpha.1` 随统一 Windows 便携版提供病例多模态分类、随机森林分类和回归。双击 `studio/启动模路.cmd`。从「工程」下拉列表选择一个合成示例，点击「创建示例…」，生成的工程会自动打开并核对数据。选择设备后点击「运行保存的工程」。

## 表格分类与回归

1. 在「实验」选择「表格机器学习（分组交叉验证）」，在「数据设置」导入 UTF-8 CSV。
2. 选择分类或回归，指定病例 ID、患者 ID 和目标列。数值列与类别列分别填写。用逗号分隔列名，列名含逗号时可填写 JSON 字符串列表。空单元格按所在折训练数据处理。
3. 指定交叉验证折数。可以选显式划分列，也可以按患者自动留出测试集。显式划分中的 `train` 与 `val` 共同构成开发集，`test` 为独立测试集。同一患者的全部病例归入同一组。
4. 检查并冻结数据摘要后应用设置。点击「创建随机森林起始图…」，或从「传统机器学习模型库」拖入随机森林组件。可在属性面板调整树数、最大深度和叶节点最小样本数。
5. 运行后查看交叉验证与测试指标。`cv_folds.json` 保存每折成员、填补值、标准化参数、类别词表和指标。`predictions.csv` 保存独立测试集逐病例预测。分类可查看准确率，回归可查看 MAE、RMSE 和有定义时的 R²。

每一折独立拟合数值填补、类别编码和可选标准化。最终模型用全部开发集重新拟合。测试或验证中出现的未知类别按训练阶段定义的编码规则处理。分类检查会报告类别覆盖不足。表格估计器在 CPU 上运行。

## 病例多模态分类

一个 CSV 行对应一个病例，影像路径相对于该 CSV 或指定的影像根目录。示例中同一行的体数据、附加 MRI 序列和表格字段共同构成输入。

```csv
case_id,patient_id,split,label,volume_path,flair,age,score
c01,p01,train,control,mri/c01/t1.nii.gz,mri/c01/flair.nii.gz,42,1.4
c02,p02,train,case,mri/c02/t1.nii.gz,mri/c02/flair.nii.gz,56,2.3
```

实际训练需要足够的病例和患者填满 `train`、`val` 和 `test`，并满足界面的类别覆盖检查。可以用程序生成的示例了解完整清单。

1. 在「实验」选择「病例多模态分类」，读取清单列。勾选数据提供的三维体、二维影像和临床表格，指定相应路径与特征列。
2. CT 使用已标定 HU 的 DICOM 序列目录或受支持的多帧文件。填写强度窗、模型间距与输入 D/H/W。MRI 选参考 NIfTI 和按通道排列的附加序列，并确认已做配准。
3. 二维输入可选择独立图片或由同病例体数据生成的中央切片、均值投影。派生视图来自物理重采样后的完整参考体。在需要两路输入时，同时勾选二维和三维。
4. 检查通过后点击「按所选端口创建分类图…」。各分支编码器可以展开编辑。画布对二维、三维和表格分别保留 `NCHW`、`NCDHW` 和 `NF` 的轴定义。选择 `cpu` 或可用的单张 `cuda:N` 后运行。
5. 对照实验沿用相同 CSV、划分和模态配置，只把本轮不用的端口名留空，再生成新的分类图。分别导出并运行工程。在「工程运行记录」打开两份记录，软件校验测试病例和预测行后显示可比指标。

临床融合列使用完整的有限数值。需要带缺失值和类别特征的表格可以通过独立的表格机器学习流程建模。三维分支以指定间距中心裁剪或填充成固定输入尺寸。病例缺失、重复或标签冲突会提示具体病例与字段。

## 复跑和交付范围

在「工程」导出后，把工程及数据复制到新目录，用界面重绑 CSV。也可以在安装了工程声明依赖的 Python 环境中，进入生成的 `project` 目录运行以下命令。数据锁记录病例、患者、划分、预处理和文件摘要。

```powershell
python run.py check --data '../example-data/cases.csv'
python run.py train --data '../example-data/cases.csv' --device cpu --out '../replay-run'
```

表格示例使用 `../example-data/table.csv`。表格和多模态工程使用 `train` 复跑并生成测试预测。多模态工程可附带匹配的模型权重。独立 `predict` 入口适用于 ImageFolder 和分割工程。比较校验用于发现记录或产物不一致，运行报告未签名。

便携版位于 `studio/dist/s14/ModelCircuitStudio`。整体移动时保留同目录的 `_internal` 和 `release-build.json`。构建命令为 `./studio/build-s4-desktop.ps1 -Stage S14`。本阶段验收使用合成病例，真实队列需要另行验证。
