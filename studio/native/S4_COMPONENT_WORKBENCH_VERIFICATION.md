## 本轮操作路径

本轮沿用DearPyGui原生桌面与现有CPU/CUDA环境。固定便携EXE仍是S3，源码版使用以下命令在独立状态目录查看；不要混淆旧EXE和本轮源码能力。

本机更方便的入口：双击`studio/启动S4源码预览.cmd`，或`studio/启动S4-CUDA源码预览.cmd`。它们使用项目已有开发环境启动原生窗口，分别将状态写到`%LOCALAPPDATA%\MLForgeStudio-S4Preview-CPU`和`MLForgeStudio-S4Preview-CUDA`，便于独立试用。启动器只检查已有环境，不安装或下载；这是源码预览入口，新便携EXE仍待后续打包。

```powershell
& '.\studio\.venv\Scripts\python.exe' '.\studio\desktop_entry.py' --data-dir '.\output\component-preview'
# 需要CUDA时使用已有CUDA环境，并在实验设置中选择实际设备。
& '.\studio\.venv-cuda\Scripts\python.exe' '.\studio\desktop_entry.py' --data-dir '.\output\component-preview-cuda'
```

1. 在左侧“组件目录”按中文/英文检索，选择分类；点击条目添加默认配置，或点击“配置”查看说明、输入输出和参数后添加。Linear/ReLU/Add有常驻快捷入口。
2. 将目录组件拖到可见画布，可直接放置到该画布的目标位置。左右/上下分屏中，拖到另一栏会明确激活该目标栏。点击添加仍可使用。
3. 需要新资源策略的工厂组件会展示当前策略与组件要求。确认“应用策略并添加”才一起修改策略并放置；取消保持原工程，Undo同时撤销这次策略变化和放置。实验batch不自动改动，运行前须自行检查。
4. 按具名端口连接。实际输入连接点在模块左侧，输出在右侧；芯片端口数量由其定义决定。完成连线采用横竖直线及90°转折；可以选中可见线段并删除。模块仍可按端口查看探针。
5. 双击芯片/“进入”打开定义页签，主模型保持打开；页签可直接切换。“单栏/左右/上下”切布局，“移栏”移动当前芯片页，“关闭”只关闭视图。主模型页固定保留。
6. 属性栏跟随当前焦点。芯片页显示定义与调用路径，并提示内部修改影响该定义的全部引用。重用定义生成新实例不会自动共享权重；“添加共享调用”仍是独立、明确的操作。

项目层级与组件结果分别滚动，搜索/分类保持常驻。长标题或打开较多页时，可以通过原生页签溢出与完整列表选择目标。空的第二栏提供实际打开芯片的操作。小型分屏中的大图仍可能超出可视范围；当前没有跨会话精确pan/zoom恢复保证。

## 已实现组件与范围

| 类型 | 实际组件 |
|---|---|
| 基础层 | Linear、Conv2d、Dropout |
| 激活 | ReLU、GELU、Sigmoid |
| 归一化 | LayerNorm、BatchNorm2d |
| 数学与融合 | Add、Concat、Multiply、Scale、OneMinus |
| 形状与池化 | Identity、Flatten、MaxPool2d、AdaptiveAvgPool2d |
| 可展开功能芯片 | MLP分类头、拼接投影融合、加权求和、门控融合、基础残差块 |
| 工程芯片 | 当前项目中有效的自定义定义及依赖闭包 |

17个primitive目录ID统一为`primitive.<kind>`；5个工厂为`head.mlp`、`fusion.concat_projection`、`fusion.weighted_sum`、`fusion.gated`、`block.residual_basic`。描述/默认值返回独立数据，工厂生成有限JSON图，不依赖UI或Torch导入。目录没有把ResNet18或尚未实现的3D/分割/文本/大模型列为可放置组件。

WeightedSum为`a + alpha*(b-a)`，alpha允许有限外推，不截断到0..1；只绑定最后的Scale，修改后不会留下失配的互补常数。GatedFusion输出features和gate，BasicBlock包含实际卷积、BN及恒等/投影残差路径。无预训练权重下载。

## 模型与工程语义

`Document.add_component`对组件配置、位置、闭包及存储/节点/深度/解析工作限制进行校验；依赖ID冲突整体迁移，添加实例/调用/布局与明确同意的策略变化是一次可撤销命令。非法输入和失败插入回滚图、revision、选择及历史。负坐标只要有限仍可合法放置。

未接线图是允许的可编辑草稿。放置成功不代表整个工程已通过聚合参数/激活预算或任务配置检查，运行前仍由统一核心校验阻止超限分配。原生目录不执行芯片包中的Python，不自动改变实验batch或旧checkpoint。

模型计算、权重身份、训练快照与视图布局分离。页签、分屏和连线绘制样式不改变模型语义；接口或参数编辑仍可能使旧结果过期。过期画布/调用上下文/已替换工程的拖放、参数和确认回调不得修改新的目标。

Python沿用受控v4静态契约。五工厂的数值/接口/共享/BN状态与受支持源码编辑往返有验证；去visual metadata后，已删除的文档/组件版本标记不能保证保留，现有导入器会重建默认版本。工厂、图覆盖和受支持AST入口拒绝非法alpha；直接以任意动态值调用独立导出的类不属于本轮额外运行时类型检查承诺。

## 连线实现与验收边界

真实DPG节点、属性端口及link ID保留，完成的原生曲线隐藏，独立绘图适配层绘制直角线并按相同可见线段命中。绘图必须裁切到当前画布并避开模块，隐藏/关闭/替换/退出时清理；弹窗出现时清除前景连线，避免遮盖表单。节点与线的选择需互斥，不能在选中新节点后误删旧线。

路由采用确定性通道、有限避障搜索和有界回退，单路搜索扩展最多4096、每画布一次重路由分配最多8192，采用最近64个障碍构建搜索网格；所有障碍仍用于最终线段裁切。首版不保证任意密集/重叠图的全局最优布线，搜索耗尽或几何重叠时可出现被遮挡的可见片段。未改变的几何/样式不会触发DPG绘图修改；不据此承诺任意规模固定帧时间。

已经完成的线采用直线/90°转折，正在拖出的临时连接预览保留可见的原生样式。小地图只公开角位置，当前使用该角25%+16px的保守遮挡区；没有冒充精确小地图矩形。离屏节点只要保有有限几何，其穿过可见画布的线段仍会被绘制、命中和正确删除。非零pan/zoom精确恢复没有认证。

用户禁止电脑控制，本轮使用真实DPG控件、应用拥有的回调及framebuffer验证。回调投放位置和连接结果可以核对；这不冒充真实OS鼠标拖拽、快捷键手势或所有显示缩放组合的人手验收。
