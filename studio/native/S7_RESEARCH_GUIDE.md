# S7 科研输入与 FitNets · v0.7.0-alpha.1

双击 `studio/启动模路.cmd` 使用 S7 统一桌面版。右侧「实验 → 设备」可选 CPU 或单张 CUDA 卡。使用源码时在已安装桌面依赖的环境运行 `studio/desktop_entry.py`。

## 科研图像、体数据和视频

选择「科研影像 / 视频分类」，在「数据设置」打开一份 UTF-8 CSV 清单。默认列为 `sample_id,patient_id,path,label`，另可指定 `split`。路径相对于样本根目录。样本 ID 唯一，患者或视频来源分组必填。同组记录留在同一个集合。显式划分使用 `train`、`val`、`test`。每个集合均需包含所有标签。普通图片、表格和图片配对表格也可继续使用已有任务入口。

| 格式 | 数据及控制项 |
| --- | --- |
| `image` | 单张常规图片，包括导出的 OCT B-scan。选择灰度或 RGB 与高宽。 |
| `gray16` | 单张高位深灰度 PNG 或 TIFF。默认按 0–65535 缩放，也可设定强度范围。 |
| `dicom` | 受支持的单文件或同一序列目录。选择 OCT、CT 或 MR。CT 解码应用存储值到模态强度的转换。对于研究中统一的 CT 窗，设置固定的低高端点。 |
| `nifti` | 单通道三维 `.nii` 或 `.nii.gz`，统一到最接近 RAS 的轴向，记录原始与重采样几何。 |
| `video` | 由随包 OpenCV 支持的单个视频，设置通道、高宽和均匀采样帧数。 |

检查通过后，从数据创建 CNN 起始图。在普通图像和高位深格式下，模型输入为 `[N,C,H,W]`。体数据和视频输入为 `[N,C,D,H,W]`，其中视频的 `D` 是时间帧。基础组件库可拖入三维卷积、三维最大池化和三维自适应平均池化。数据清单记录采样和变换，并在训练时复核内容。当前几何处理覆盖单通道体分类的固定尺寸重采样。多序列配准、分割标注同步变换与原始空间恢复仍需专门的处理流程。按样本的强度缩放适合形状检查。需要跨患者可比的物理强度时，请根据研究协议设置固定范围。

## 两阶段蒸馏

1. 选择「CSV 数值分类」「ImageFolder 图片分类」或「科研影像 / 视频分类」，完成数据检查。
2. 点击「创建教师起始图」，保留当前数据与模型输入配置。用分类任务训练教师，记下其 `best.pt` 路径。也可使用权重键、形状、类型与类别顺序吻合的教师检查点。
3. 点击「创建 FitNets 双分支图」。数据设置中填入教师 checkpoint，设置提示轮数、温度和蒸馏权重。主实验面板的 Epochs 控制第二阶段轮数。
4. 运行后，第一阶段拟合教师提示特征，更新学生前缀和投影器。第二阶段以真实标签和教师软目标训练学生分类器。训练期间教师保持评估模式，参数和缓冲区都固定。
5. 在结果页查看两阶段损失、独立测试集指标和输出探针。产物含数据清单、教师权重哈希、阶段记录、学生独立图和最佳学生 checkpoint。两个阶段顺序执行。当前阶段检查点用于检查和复用模型权重。

图的教师、学生和投影分支可以独立展开。图与 Python 往返描述模型结构。FitNets 的实验设置随工作区 JSON 保存。该功能对应 Romero 等人的 FitNets 知识蒸馏流程。服务器已有的病理性近视 FIT-Net 是不同的研究模型。

## 验收

- 本地合成图像验证 16 位强度、DICOM 几何、CT 强度变换、OCT 多帧、NIfTI 方向及均匀抽帧。在实验室服务器上，以 CPU 只读验证了 3 张实际 OCT JPEG 和 3 张实际 OCTA PNG，均可转换为有限值、归一化的灰度张量。同一服务器还验证了 3 个 OCT NIfTI 体数据，解码到有限的 float32 `[1,12,32,32]` 张量并核对方向信息。这 3 个样本来自既有测试分区，用于读取验收。`.mha` 和 `.npy` 尚待支持，真实 CT、MRI 与医学视频样本仍需验收。
- 本地原生桌面程序使用合成 NIfTI 在 CPU 与 `cuda:0` 完成教师训练与两阶段蒸馏。两个阶段的权重变化、保存重开与图的 Python 往返均通过。
- 验收测试输入仅用于核对工程流程。实际科研数据应保留数据许可、患者划分和实验记录。
